# 法拍屋追蹤

自動抓取司法院「法拍屋查詢系統」中**全國各縣市**的房屋拍賣資料，存進 SQLite，並以網頁儀表板瀏覽、篩選、追蹤每個標的的降價與拍定歷程。

只用 Python 標準函式庫（需 Python 3.9+），不需安裝任何套件。

## 快速開始

```bash
python3 server.py
```

開啟 http://localhost:8000 。伺服器啟動時會立即抓一次，之後每 6 小時自動更新；頁面上也有「立即更新」按鈕。

```bash
python3 server.py --interval 2      # 每 2 小時更新
python3 server.py --interval 0      # 不自動更新（搭配 cron 使用）
python3 scraper.py                  # 只抓資料、不開網頁
```

## 抓了哪些資料

| 類別 | 說明 |
|---|---|
| 一般程序 | 進行中的拍賣（第 1～N 拍），含總底價、拍賣日、點交與否、權利範圍 |
| 應買公告 | 特別程序（四拍未拍出後的公告應買期間） |
| 拍定價格 | 已拍定標的的成交價，用來算溢價率 |

抓取範圍設定在 `config.json`，例如 `"counties": ["臺北市", "新北市"]`，空陣列 `[]` 代表全國。修改後下次更新即生效，網頁只顯示設定中的縣市。詳見系統說明文件 8.3 節。資料來源同一筆案號、標別、拍賣日的多筆建物會合併為一個「標的」。

## 追蹤邏輯

- 每次抓取都寫入 `rounds` 表，所以同一標的從一拍 → 二拍 → 三拍的底價變化都會保留，表格的「較首拍」欄顯示降幅。
- `lots.status`：`active` 拍賣中 / `special` 應買公告 / `stopped` 停拍 / `sold` 已拍定 / `ended` 拍賣日已過且未再出現（流標後未再公告或撤回）。
- 「新上架」以本系統首次抓到的時間判斷，所以第一次執行時不會標示新上架。
- 單價只計算權利範圍「全部」的標的（持分的單價沒有意義），面積為建物登記面積。

## 用 cron 定期更新（可選）

不想一直開著伺服器時，可以用 cron 每天抓一次（頻率建議見系統說明文件 9.4 節）：

```
0 18 * * * cd /home/tunyuan/houses && /usr/bin/python3 scraper.py >> data/scrape.log 2>&1
```

完整的系統說明（架構、資料來源、資料庫、API、維運、疑難排解）請見 [docs/系統說明.md](docs/系統說明.md)。

## 檔案

- `config.json` — 設定檔（抓取範圍）
- `scraper.py` — 爬蟲與資料庫邏輯
- `server.py` — 本機網頁伺服器與 API（`/api/lots`、`/api/history?key=`、`/api/status`、`POST /api/refresh`）
- `static/index.html` — 儀表板
- `data/houses.db` — SQLite 資料庫

## 注意

- 司法院網站憑證缺少 Subject Key Identifier，Python 3.13+ 預設會拒絕；程式只關閉 X.509 strict 檢查，仍會驗證憑證。
- 請保持合理的抓取頻率（程式在分頁之間會暫停 1 秒）。
- 資料僅供參考，投標前務必詳閱法院拍賣公告（點交、占用、增建等資訊都在公告 PDF 中）。
